# Drafts

Draft milestone plan pairs that are not yet in the
[milestone register](../plans/README.md). The register allows one Open
lookahead beside the current milestone. Each draft here moves into
`docs/plans/` as that lookahead when the milestone before it closes, and is
refined until then. A draft authorizes nothing, and its version labels are
projections.
